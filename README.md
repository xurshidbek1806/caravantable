## Overview

CaravanTable brings connections, queries, table data and schema tools into one clean native desktop experience. It is built for developers who want the essentials of a professional database client without a heavy workflow.

This repository is CaravanTable's official public product page for releases, documentation, feedback and security notices. The application source code is maintained privately.

## Key capabilities

- Connect to PostgreSQL, MySQL and SQLite databases
- Work in a SQL editor with query results and execution history
- Use Safe Mode protection for destructive statements
- Filter and edit table data in a quick visual grid
- Import and export SQL/data as part of everyday workflows
- Inspect schema details, including columns, indexes, foreign keys and DDL
- Connect to remote databases with SSH tunnel support
- Choose between native light and dark themes

## Supported platforms and databases

### Platforms

CaravanTable is designed for macOS, Windows and Linux using Tauri, Rust and Svelte.

### Databases

- PostgreSQL
- MySQL
- SQLite
