  # CaravanTable

  **A fast, focused desktop database manager for everyday work.**

CaravanTable brings connections, queries, table data and schema tools into one clean native desktop experience. It is built for developers who want the essentials of a professional database client without a heavy workflow.

## Highlights

- PostgreSQL, MySQL and SQLite connections
- SQL editor with query results and execution history
- Safe Mode protection for destructive statements
- Quick visual filtering and editable data grid
- SQL/data import and export workflows
- Table columns, indexes, foreign keys and DDL views
- SSH tunnel support for remote databases
- Native light and dark themes

## Platforms

CaravanTable is designed for macOS, Windows and Linux using Tauri, Rust and Svelte.

## Availability

CaravanTable is free to use. Public builds and release notes will be published on the [Releases](https://github.com/xurshidbek1806/caravantable/releases) page.

The application source code is maintained privately. This public repository is the official product page for releases, documentation, feedback and security notices.
